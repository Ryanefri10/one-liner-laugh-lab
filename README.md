One short funny line answering a prompt: the excuse a robot vacuum gives after eating a sock.

> The sock was already dead — single, lonely, its partner lost in the wash years ago. I just gave it the burial it deserved. Inside me.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Deterministic: one constant, no network, no randomness, no clock.
